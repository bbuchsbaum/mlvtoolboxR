# Plan for testing vector-based junction recovery

1. Train a T and an X scorer using a hash-selected subset of 320 photographs from the official Wireframe training split. Inputs are the directions, lengths and confidence of predicted HAWPv2 lines and photographic line fragments around a candidate. Keep the issue manifest and the 256-pixel input fixed.
2. Choose score thresholds on the previous 23 development, 24 replication and 48 confirmation photographs. Compare the candidate with the complete experimental detector from `b2cd454`. Favor the best recall of the weaker class within the previous total detection count and reviewed-gap flag count. Use the original 24 issue photographs to diagnose transfer to the frozen labels. Disclose any changes after inspecting them.
3. Reserve the first 64 remaining Wireframe test photos ranked by SHA-256 of `issue3-topology-v1/` plus the photo ID. Exclude all previously used photo IDs. Freeze model and thresholds before inspecting their performance. Primary targets are at least 50% recovery for each type and a material improvement over the previous detector. Report per-type recall, the total number of detections, reviewed-gap flags and paired uncertainty across photographs. Report the earlier 24-photo result separately.
4. Have Codex Astra review photograph crops with method identities, model scores and reference labels withheld. Screen the proposed near-miss sites before comparing proximity flags. For visual precision, draw 24 points per type from each method uniformly, shuffle them with 12 reference sites, and ask for the visible type. Count indeterminate cases explicitly. This provides an AI visual audit on the sampled photos.

## Finalist rule, before scoring the 64 photos

The single-scale model with image gradients recovered 36/62 Ts and 51/101 Xs on the original 24, with 0/15 reviewed gaps flagged. Threshold selection used the 95 calibration photos. We will replace it with the multiscale model only if the latter also recovers at least half of each type on the original, preserves 0/15 there, and improves the smaller of the two pooled calibration recalls within the same density and gap limits. This use of the original panel makes it part of model selection. The 64 remaining photos are the prospective test. For both models, refine the same initial threshold grid by multiplying each coordinate of its best eligible setting by 0.85, 1 or 1.15.

Two Codex Astra reviewers will independently classify the same shuffled 96 sampled detections and 12 interspersed reference sites. The primary visual result counts an unclear rating as unconfirmed. Report both reviewers separately and their agreement, including how often they recognize the reference controls.
