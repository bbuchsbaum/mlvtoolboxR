# Contour-guided T and X selection

Use the shipped experimental context scorer as the fixed photo detector. Run four variants on the same candidate probabilities: context alone, stem continuity alone, crossing-track identity alone, and both. Make each candidate decision from photographs and model outputs. References, scene categories and reviewed gaps are evaluation inputs only. Fix the geometry rules using synthetic cases before scoring any Toronto confirmation photographs.

Split the Toronto artists’ drawings by photograph within each of the six categories. Use ten per category for development, fifteen for confirmation, and keep the remainder for future work. Check source dimensions, alignment, and possible duplicates before interpreting confirmation. Prior exploration counted reference records across the dataset. It used no model outputs from these photos. Record any overlap and the coverage of the duplicate search.

For gaps, reproduce the frozen 51-photo York baseline, then count accepted review controls with any T/X within four pixels. This is a reused challenge set. Compare the two T rankings at the same pooled number of one-to-one T matches as well as at their actual operating points. Any unchanged X still counts as a gap flag. Compare the primary crossing change at the same number of X predictions per photo as the context detector, and also report the uncapped results. Use maximum-cardinality matching by type within four working pixels.

On Toronto score both the proposed junctions and junctions recovered from the actual output drawing by the R package. For drawings compare contour pixel coverage and precision within two working pixels, ink pixel counts, and position-plus-incident-direction agreement where artist directions can be recovered. Evaluate all four variants with the same rendering procedure. Report by category and bootstrap paired photos within category. Confirmatory evidence for a change requires a gain over its relevant comparator on its intended outcome, without sacrificing the other junction type, or gaining agreement primarily by drawing substantially more ink. Report adverse results and retain the frozen detector in that case.

Before opening Toronto outcome scores, we added an eight-pixel synthetic gap at the end of an observed finite stem and a positive control with the same endpoints over continuous ink. The first implementation ignored stems ending outside the 2.5-pixel contact window. The corrected rule considers a unique aligned stem ending within ten pixels of a measured bar (the established near-miss range), and follows contrast across that interval. Its first two samples are excluded because the bar itself occupies the junction. In an initial replay on the reused York photos the earlier version had 675 T and 373 X matches for the stem check, and left all ten proximity flags and the one connected gap. The Toronto confirmation comparison uses the corrected rule. No Toronto outcome scores informed this change.
