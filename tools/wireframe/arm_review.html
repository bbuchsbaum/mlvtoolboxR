Photographic junction review

Work independently. A T has a visible through-edge and a terminating stem. An X has four visible arms along two crossing axes. Count arms extending about ten original pixels or more. A gap has a stem ending roughly 10–25 pixels before a target edge. Place it where the stem would meet the target. Use unclear when the photo cannot settle the class.

Do the regions first. Click every clear T, X and genuine gap centered inside the dotted border. Use the surrounding pixels as context. Choose a label before each click. Mark the region complete even if it contains no junctions.

Each target has two views of the same pixels. The cyan corners surround the scoring area. Classify the junction nearest the center, using other for a clear corner, line or texture with neither a junction nor a genuine gap.

Save before closing. Each reviewer returns their own JSON file. All images and ratings stay on this computer.
