# Summarize a collection of drawings

Summarize a collection of drawings

## Usage

``` r
batch_statistics(drawings, image_ids = names(drawings), ...)
```

## Arguments

- drawings:

  List of drawings.

- image_ids:

  Unique drawing identifiers; defaults to names or sequence.

- ...:

  Arguments to contour_statistics.

## Value

Long statistics data frame with image_id.
